# Проект: Браузерная текстово-кнопочная онлайн-игра

## Стек технологий
- **Backend**: .NET 9, C#
- **Архитектура**: CQRS с использованием MediatR, DDD
- **Frontend**: React, TypeScript
- **Стили**: Tailwind CSS
- **База данных**: PostgreSQL
- **State management на фронте**: RTK Query (Redux Toolkit Query)

## Структура проекта
- `/src/Host` — стартовый проект на .NET
- `/src/Host/ClientApp` — клиентская часть на React
- `/src/Domain` — доменный слой
- `/src/Application` — слой Application
- `/src/Infrastructure` — слой Infrastructure

## Конфигурация HTTPS и SSL
- **Используется**: Let's Encrypt с автоматическим обновлением (через FluffySpoon.AspNet.LetsEncrypt)
- **Конфигурация сервера**: `/src/Host/Program.cs`
- **Настройки SSL**: `/src/Host/appsettings.json` (секция `LetsEncrypt`)
- **Автообновление**: каждые 30 дней до истечения срока действия сертификата
- **Порты**: HTTP (80), HTTPS (443)
- **В Development**: HTTPS отключен для локальной разработки

## Основные правила разработки
- стараться избегать файлы больше 200 строк (по возможности разбивать)
- стараться избегать методов больше 27 строк (по возможности разбивать)
- стараться избегать больше 12 файлов и папок в одной папке

### Backend
- Все бизнес-операции реализовывать через CQRS (Command/Query + MediatR)
- Валидацию запросов делать через атрибуты
- Обрабатывать ошибки через глобальный middleware (Problem Details, кастомные исключения)
- Для работы с БД использовать Entity Framework Core
- Все эндпоинты — RESTful

### Frontend
- Архитектура — FSD
- Компоненты — функциональные, с хуками
- Стили — Tailwind
- API-запросы через RTK Query
- Типизация — строгая TypeScript (никаких `any` без крайней необходимости)

### База данных
- Все изменения БД — через миграции (Code-First)
- Индексы добавлять с умом (по внешним ключам и часто фильтруемым полям)

### Общее
- Код должен быть читаемым, с осмысленными именами переменных и методов
- Не коммитить секреты (.env, appsettings.Development.json, ключи)
- Перед коммитом — убедиться, что проект компилируется (dotnet build) и фронт собирается (npm run build)
- Логирование — через ILogger на бэке, на фронте — console.log только для разработки
